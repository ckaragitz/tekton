# Test-Kit Report Card — open each file in Revit, note what happens

Thanks for doing this. Every one of these files was **generated by our software,
not by Revit** — no Revit install, no Autodesk seat was involved in making them.
Autodesk's cloud viewer already accepts and renders them; **you are the first
person to open them in real desktop Revit**, so honest notes beat kind ones.

**First: which Revit version do you run?** These `.rvt`/`.rfa` files are
**Revit 2026 format**, and Revit only opens files from its own release or
older — **Revit 2025 or older will refuse every file in this kit** (usually a
"created in a later version" dialog). If that's you: (a) the exact dialog
text is still a genuinely useful data point — please send it — and (b) a
**Revit-2025-native kit is in certification now**; you'll get it the moment
it passes. If you have access to Revit 2026 anywhere (a trial seat counts),
that's the fastest way to run Track A today.

For **each file**, please jot down:
1. **Did it open?** (yes / opened with warnings / refused — copy any dialog text)
2. **Warnings dialog on open?** (Revit's "Review Warnings" list — screenshot or count)
3. **Does the model look right?** (walls/equipment where you'd expect, or missing/invisible)
4. **Can you edit and save?** (move something, save-as, reopen)
5. **Anything Revit "fixes" or complains about** (regeneration, upgrade prompts, etc.)

Screenshots are gold. So is the exact text of any error.
