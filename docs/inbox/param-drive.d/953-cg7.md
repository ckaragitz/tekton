# #953 — CG7 corrected to the born law (END locks pin one end; the plane is its surface)

Stream: param-drive. Issue: #953. Territory: `src/rvt/famgen/constraint_law.py`
(+ its `plugin/lib` mirror), `tests/test_cg7_953.py`, `tests/ci_shard.d/953-cg7.txt`,
this fragment.

## The problem

CG7 ("a sketch lock's curve lies on the plane it is locked to") reported
**139 errors** over the host documents of the 421-family Revit-born reference
library (53 host documents). A law that fires on Autodesk's own output is wrong
by definition (the #910 precedent retired CG2 for 22 false errors).

## Census — what the 139 findings flag

The library is a git-ignored development instrument; only counts and field
facts are cited here. Instrument: every `Alignment` carrying
`SketchMembership{VarSketch}` in every document unit (host + 4,425 nested
units, 0 read errors), judged exactly as the old CG7 selected (one plane
witness, one curve witness).

Old reading: 18,586 sketch locks; 10,847 judged (347 host). Failing: 410
(139 host, 53 host documents). Every failure is `m_flags` 30, every plane
parallel to its own surface — the plane's *position* and the *points judged*
were the two things wrong:

| class | host | all units |
|---|---|---|
| GLine END lock (geomTag 0, subTag 0 / 1) judged on its free end — holds once only the witnessed end is judged | 103 | 316 |
| GLine END lock that also needs the plane's surface (both corrections) | 6 | 22 |
| GLine whole-line lock (subTag -1) to a plane whose drawn ends are off its own `m_pSurface` | 18 | 60 |
| GArc centre lock (geomTag 1) to such a plane | 12 | 12 |
| **total** | **139** | **410** |

Field facts behind the two corrections:

- subTag 0 / 1 on a `GLine` witness is the line's start / end point (the same
  reading CG10 already uses for a line-end dimension witness). Of the judged
  born END locks, 316 + 22 have the other end off the plane — a line ending on
  a plane, not lying in it. Among passing locks only 11 END locks happened to
  have both ends on the plane.
- 94 of the 10,847 judged born locks are to a plane whose drawn ends
  (`m_freeEnd` / `m_bubbleEnd`) lie up to 6.5 ft off its own surface
  (`m_pSurface` origin / x / y), parallel to it; the curves sit on the surface
  in every one (max offset 2e-12 ft). CG8 and CG10 already read the surface
  (`plane_of_any`); CG7 was the one rule still on the drawn ends.

## Decision: corrected, not retired

A true law exists and holds without exception, so CG7 is corrected:

- the plane is the `RefPlane`'s own surface (`plane_of_any`; drawn ends only
  when there is no surface);
- a `GLine` witnessed whole (subTag -1) pins both ends; witnessed at an END
  (subTag 0 / 1) pins that end only; any other subTag is not judged;
- a `GArc` centre lock (geomTag 1) pins `m_center` (unchanged).

`lock_points` takes an optional `sub_tag`; `None` keeps the old both-ends answer
for CG9 / CG10, which call it without one.

No viewer / desktop-Revit claim is made (hard rule 4): this is a fact about
our instrument agreeing with born files, not about Revit accepting ours.
