## What was built

One guard and one helper in `rvt.famgen.factory`.

`make_luminaire`'s troffer type description formatted six figures with
`{value:g}` / `int(value)` and guarded none of them:

```python
(f"Recessed LED troffer {j_size}, {j_watt:g} W, {fx.get('lumens_lm'):g} lm, "
 f"{int(fx.get('cct_k'))} K, ...")
```

The `2BLT2` (2x2) member carries no photometrics — `wattage_w`, `lumens_lm`
and `cct_k` all resolve to `None`, kind `assumed` — so **every troffer size
except 2x4 raised `TypeError: unsupported format string passed to
NoneType.__format__`** before a byte was written. Supplying an explicit
`wattage` did not help: the next placeholder reads `lumens_lm`, also `None`.

The downlight branch of the same expression already guarded its unknowns
(`{fx.get('lumens_lm') or '?'} lm`). Only the troffer branch was missed.

`_figure(value, fmt="g", unknown="?")` now renders an unsourced figure as `?`.
Unknown stays unknown — not raised on, not fabricated (steer S-2026-08-11-a:
"a parameter's value is filled only when it is known ... an invented value is
not"). Sourced figures format exactly as before.

## Findings not fixed here

1. **The type row still writes `0.0` for an unknown figure** —
   `("Wattage", "wattage", float(j_watt) if j_watt else 0.0)`, same for lumens
   and CCT. So a 2x2 troffer carries **0 W / 0 lm / 0 K** rather than an empty
   parameter. Under S-2026-08-11-a read strictly, an empty parameter is correct
   and `0` is invented. Deliberately untouched: it changes value semantics for
   every luminaire, and belongs in its own issue. Recorded in #682.
2. **Same latent pattern in `make_transformer`** — its description formats
   `{fx.get('depth_in'):g}` unguarded (~line 1947). It does not crash today
   only because the resolver refuses a null-dimension variant first. One
   catalog edit from the same bug.
3. **The Square D panelboard catalog is unreachable.** 288 of the 459 refusals
   are `no panelboard facts line for square-d/nq-nf-iline; known: [('eaton',
   'pow-r-line')]`. We ship NQ / NF / I-Line facts that no constructor can
   use. Honest refusal, dead catalog — worth its own issue.
