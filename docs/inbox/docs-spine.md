## Method note — the honest coverage numbers (reproducible)

The critic's H3 rule: lead with certified %, print proven-uncertified
separately, strip the free read cells (every read cell is a green that
merely samples a corpus decode). From the fresh `matrix.json`:

```python
# statuses over 168 cells: CERTIFIED 20, VALIDATES 61, UNPROVEN 40, MISSING 31, NA 16
applicable = 168 - 16 = 152          # NA excluded
certified  = 20 / 152 = 13.2 %
proven     = (20+61) / 152 = 53.3 %   # the retired headline (VALIDATES = viewer-PENDING)
read cells = 28, all VALIDATES (27 via probes)   -> the free greens
mutating   = (81-28) / (152-28) = 53 / 124 = 42.7 %   # create/modify/move/retype/delete only
mutating-certified = 20 / 124 = 16.1 %
```

(The 2026-08-03 critique quoted 43.2 % = (81−27)/(152−27); the difference
is stripping all 28 read cells vs the 27 probe-based ones. 42.7 % strips
every read; either way state the method beside the number.)
