## Why

#670 hoisted the four test-module copies of `{e.path: e.data for e in read_entries(p) if e.entry_type == "stream"}` into
`tests/conftest.streams`, and named three more places its tests-only territory could not reach: `tools/genesis_deletion.py:935-936`
(`stream_identity`), `tools/genesis_addpath_probes.py:227` / `:1194` (`load_material` / `certify`), and a *nested*
`def streams(p)` inside `tests/test_famload_batch.py::test_chain_and_batch_are_logically_identical` (invisible to the
scaffolding law's top-level ratchet by design). The engine-shaped home is beside `read_entries` / `catalog` in
`src/rvt/roundtrip.py` -- the move #640 made for `rewrite_entries`, after which conftest's helper became a thin call.

## What landed

1. **`src/rvt/roundtrip.py::read_streams(path: str | os.PathLike[str]) -> Dict[str, bytes]`**, placed directly after
   `read_entries` in the "reading" section: `{e.path: e.data for e in read_entries(os.fspath(path)) if e.is_stream}` --
   streams only (root and storages dropped), in `read_entries` (stream-id) order, raw = as stored (still framed / paged).
   Five-line docstring, contract only. `e.is_stream` is `CfbEntry`'s existing property (`cfb_writer.py:124`), so the file's
   only literal `entry_type == "stream"` left is `rewrite_entries`' own loop. Plugin mirror `plugin/lib/src/rvt/roundtrip.py`
   regenerated by `tools/sync_plugin.py` (the only plugin delta).
2. **`tests/conftest.streams`** -- body is now `from rvt.roundtrip import read_streams; return read_streams(path)` (lazy import,
   as its neighbours); NAME kept, so #679's adopters (`C.streams(...)` in four modules) and the law's `SHADOWS` row are
   untouched; docstring's parenthetical now reads "(= `rvt.roundtrip.read_streams`, #677)", the same shape as
   `rewrite_streams`' "(= `rvt.roundtrip.rewrite_entries`)" two functions down.
3. **Adopters** (reader adoption only, nothing else in any of them):
   * `tests/test_famload_batch.py` -- the nested `def streams(p)` deleted; `cs, bs = read_streams(cur), read_streams(bout)`;
     the function-local import becomes `read_entries, read_streams` (`read_entries` is still used by the `bfi()` helper at :246).
   * `tools/genesis_deletion.py` -- `stream_identity`: `a, b = read_streams(base), read_streams(out)`; the module import
     `read_entries` -> `read_streams` (that was its only user; column alignment kept).
   * `tools/genesis_addpath_probes.py` -- `certify` :1194: `probe_raw = read_streams(out)`; import `read_entries, read_streams`.
4. **`tests/test_read_streams_677.py`** (new, 5 ids) + drop-in `tests/ci_shard.d/677-read-streams.txt`: (a) on the `pin`
   fixture, `read_streams(Path(pin))` vs `read_entries(str(pin))` -- what is dropped is exactly `{"root", "storage"}`, key order
   == the stream entries' order, bytes == their `.data` (PathLike and str in one row, two reads); (b) per certified year
   (2024/2025/2026), `read_streams(p)` == `{s.name: doc.raw(s.name)}` over `rvt.container.open_rvt` -- an independent reader
   as oracle: every stream, no storage, raw = still paged; (c) `tests/conftest.streams` IS the engine call: `monkeypatch`
   `rvt.roundtrip.read_streams` to return a sentinel, `C.streams("any.rvt") is sentinel` (zero reads; a re-forked copy in
   conftest would go red here, which mere equality of two reads would not catch).
5. **`tests/test_conftest_scaffolding.py` -- not touched, on purpose.** `REWRITE_PASS = {"read_entries", "write_cfb"}` stays
   exact: `read_streams` drops storages / CLSIDs / state bits / FILETIMEs, so no module can hand-roll the container-rewrite
   pass through it (`read_streams` + `write_cfb` in one module is the "census + builder" case the law already declares green).
   `read_streams` cannot join `SHADOWS` (conftest imports it function-locally, so it is not in `vars(conftest)` and the
   staleness check would go red) and adding it to `FORBIDDEN`'s extras would be a speculative spelling nobody ever bound --
   against that ratchet's own "retired spellings that actually existed" rule; the one spelling this PR retired under `tests/`
   was nested, which `_top_level_names` does not see by design, and `streams` is already a shadow. Law green 18/18 unchanged.
