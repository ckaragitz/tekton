## What was built

- `src/rvt/` — the engine (23 modules): container/de-paging, **the cracked
  ECC** (`ecc.py`), full 4,690-class schema, object decoder (100 % of the
  corpus), **byte-exact encoder** (1,153,554 records / 397 classes, 0
  failures), 6 small-stream encoders, mutation API (`mutate.py`),
  **commit layer** (`commit.py`), writer/framing, CFB writer.
- The ECC: reverse-engineered from a real `Utility.dll` (Revit 2023.1.9,
  extracted from Autodesk's public update EXE) — `Foundation\Utility\
  CRCIO.cpp`, 255-lane bit-interleaved CRC-11; reproduced byte-exact on
  3,502 pages + 55 partial blocks + 45 whole streams; independently
  re-derived by pure math and validated on 2016–2026 files.
- Tests: **179 passing**.
- `tools/spec_to_rvt.py`, `tools/ifc_to_spec.py` — the generators.
- `plugin/` — the shippable plugin: skills `revit-bridge` (IFC, proven)
  and `rvt-native` (native .rvt, now proven incl. creation), 4 agents,
  3 `/revit-*` commands, the bundled `lib/` (fresh-install smoke test
  passes), both use-case examples with delivery reports, honest status.
- `usecases/` — the two customer bundles: Chicago-plenum room
  (31.4 -> 89.0 hardened -> 100/100 regenerated IFC **+ native
  electrical-room.rvt**) and Eaton panelboard (98.8/100 + shared-params).
