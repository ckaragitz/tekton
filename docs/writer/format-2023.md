## 1. THE 2023 DELTA -- element ids are 32-bit (the record layer)

2023 is the first release in the roster whose data layer genuinely differs from 2026: **Revit 2024 widened element ids from 32 to 64 bits**.  The file's own schema declares it -- class `Identifier` is **v1** with field `m_id` (kind 0x4 = i32) where 2024/2025/2026 declare v2 `m_id64` (i64).  Ripples, all measured and proven by decode parity + byte-exact round-trips:

| layer | 2023 (32-bit era) | 2024+ |
|---|---|---|
| record header, seq-101 | `<iI` = 8 B | `<qI` = 12 B |
| record header, seq-102/103 | `<iII` = 12 B | `<qII` = 16 B |
| in-body `ElementId` / `Identifier` | i32 | i64 |
| `Global/ElemTable` row | 28 B, order (original_id, id, ce, me, ue, partition, owner) | 40 B, order (orig, ce, me, ue, id, owner, partition) |
| `ElemTable` footer | 19 B (u32 last_id, u8 pad) | 24 B (u64 last_id, u16 pad) |
| owner-invalid sentinel | `0xffffffff` | `0xffffffffffffffff` |
| `ElemTable` class version | v9 (no `m_bLastElementIdOverride`) | v10 |
| `ElemRec` schema field order | m_id, m_history, m_partitionId, m_OwningElementId | m_history, m_id, m_OwningElementId, m_partitionId |

Everything else is UNCHANGED at 2023: CFB container (v4, 4096-byte sectors), page/ECC framing, gzip flavour, block framing (bar the usual per-release ordinals), the schema-stream grammar (`rvt.schema.parse` reads it to EOF -- `PARSER_DELTAS = ()` for the fourth consecutive release), the class field lists (ElementHeader v24 = 2024's, FamilyInstance v37 = 2024's), the stream roster.  The reversible patch set that puts the read/write stack into the 32-bit era is `rvt.versions.records32` (activation keyed off the schema's own Identifier declaration, NOT the release number).

## 7. The 2023 emit context (what a 2023 write needs active)

`tools/genesis_2023.py context_2023` composes, and each layer restores on exit:

1. `rvt.versions.records32.ids32()` -- the 32-bit record layer (framing walks, in-body ids, ElemTable wire codec, emit paths; ~40 patch points, table in records32.py).
2. `rvt.versions.reading(src)` -- the six framing ordinals bound into `rvt.partitions`.
3. The module-local framing-tag copies (`rvt.reduce` / `rvt.manipulate` / `rvt.commit` / `rvt.writer` BLOCK/TRAILER tags; `rvt.famgen.factory` CD_SEPARATOR/CD_END_RECORD rebuilt from the active ordinals) -- the genesis_2025 `_LOCAL_TAG_PATCHES` list, re-verified for this stream.
4. `rvt.adocument._DECODER` bound to the 2023 schema.
