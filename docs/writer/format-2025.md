## 4. Identity / footer / version markers

* `BasicFileInfo` format string: **`2025`**, build: **`Development Build`** (the 2025 samples are Autodesk 'Development Build' releases)
* `Global/History` upgrade-version list: 2025 ends **2662** (190 entries) -- IDENTICAL to 2026 (2662, 190 entries) AND to 2024 (measured directly).  **CORRECTION to the KNOWLEDGE.md gloss '2662 = Revit 2026': 2662 is the ADocument schema `version` stamp in the 2024, 2025 AND 2026 schemas** (verified from each release's own `Formats/Latest`) -- the document format version froze at 2662 before 2024; the History terminal value is therefore NOT a release marker, and writing 2662 is correct for all three creation targets.  The RELEASE-authoritative marker is `BasicFileInfo` `Format:` (what `rvt.versions.detect_release` keys on).
* `Global/ElemTable` lead class tag: 2025 `0x5ab` vs 2026 `0x5c9` (= `ElemTable` -- an ordinal, resolved by name)
* `ElemTable` footer tail class: 2025 `0x93b` vs 2026 `0x96a` (= `IdentifierSource`)
* `Global/History` lead class tag: 2025 `0x51d` vs 2026 `0x538`

These stream-lead tags round-trip automatically through the decoders (they preserve the decoded `class_tag`); only a from-scratch 2025 stream author needs the table above.

## 6. The module-local baked-tag patch set (plan SS7 risk, found REAL)

`rvt.versions.reading` patches `rvt.partitions`; these module-LOCAL copies of the framing ordinals had to be patched too (`tools/genesis_2025.py context_2025`) before any 2025 emit:

| module | attr | why |
|---|---|---|
| `rvt.reduce` | `BLOCK_TAG` (local literal 0x0F28) | `NewBlock.frame` writes block headers |
| `rvt.reduce` | `BLOCK_TRL_TAG` (from-import) | block trailer mirror |
| `rvt.manipulate` | `BLOCK_TAG`, `TRAILER_TAG` (from-imports) | the modify path re-frames blocks |
| `rvt.commit` | `BLOCK_TRL_TAG` (from-import) | commit re-frames touched blocks |
| `rvt.writer` | `BLOCK_TRL_TAG` (module constant) | reframe_blocks |
| `rvt.famgen.factory` | `CD_SEPARATOR`, `CD_END_RECORD` (bake 0x3A3/0x3A2) | ContentDocuments grammar (2025: 0x391/0x390) |
| `rvt.adocument` | `_DECODER` (cached 2026-schema decoder) | ADocument decode/encode must use the file's schema |

Proposed permanent fix (for the versions stream / orchestrator): fold these into `rvt.versions.activate` so `reading()` covers the emit path too; until then `context_2025` is the working recipe.
